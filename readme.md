Creamos una aplicacion para veterinarias, la cual puede crear usuarios, categorias y reservas.
En la misma se puede aparte de crear, modificar, eliminar y listar tanto usuarios, categorias y reservas, para todas las opciones
es necesario estar logueado y se valida por token, hay funciones que solo estan disponibles para el rol admin.
Tenemos una api externa la cual te muestra un codigo QR con los datos de la reserva, con la ia lo que implementamos fue un arreglo en el texto que 
ingresa el usuario para dejarlo un poco mas prolijo y formal.
